 МедКалькулятор

Медицинские калькуляторы и шкалы для врачей. Открытый некоммерческий проект.

🔗 Демо

https://seledkabezglaz.github.io/med-calculator/

Что внутри

- Антропометрия и нутрициология
- Педиатрия и неонатология
- Акушерство и гинекология
- Кардиология
- Нефрология
- Неврология и психиатрия
- Гастроэнтерология и гепатология
- Эндокринология
- Хирургия и неотложная помощь

  
 Как пользоваться

 Открой ссылку на демо. Выбери калькулятор, заполни поля — результат появится сразу.

  Технологии

- Чистый HTML + JavaScript
- Данные — в `formulas.json`
- Без бэкенда, работает в браузере

  Дисклеймер

Все расчёты носят справочный характер и **не заменяют консультацию врача**. Клинические решения принимает лечащий врач.
