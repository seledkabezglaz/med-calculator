# МедКалькулятор

**Медицинские калькуляторы, шкалы и справочники для врачей.** 
Открытый некоммерческий проект. Без рекламы, регистрации и трекеров.

🔗 **[Открыть демо](https://seledkabezglaz.github.io/med-calculator/)**

## 📱 Особенности

* **Более 100 инструментов:** формулы, опросники и шкалы.
* **Справочник МКБ-10:** более 12 000 болезней с быстрым поиском.
* **Работает офлайн:** устанавливается на главный экран телефона как PWA (приложение).
* **Поиск и категории:** быстрый поиск по названию, а также распределение по специальностям (папкам).
* **Избранное:** возможность закрепить нужные инструменты на главном экране.

## 🩺 Что внутри

* Антропометрия и нутрициология
* Педиатрия и неонатология
* Акушерство и гинекология
* Кардиология
* Нефрология
* Неврология и психиатрия
* Гастроэнтерология и гепатология
* Эндокринология
* Хирургия и неотложная помощь
* Справочник МКБ-10 (в разработке: алгоритмы СМП)

## 🛠 Как пользоваться

1. Перейдите по ссылке на демо.
2. Выберите нужный раздел в нижнем меню (Расчеты, СМП, МКБ-10).
3. Найдите инструмент через поиск или выберите папку с нужной специальностью.
4. Заполните поля — результат появится мгновенно.
5. Для работы без интернета установите приложение на главный экран (инструкция есть в меню приложения).

## ⚙️ Технологии

* Чистый HTML + JavaScript (без тяжелых фреймворков).
* Данные хранятся в `formulas.json` и `icd.json`.
* Работает в браузере без бэкенда.
* PWA (Service Worker) для офлайн-режима.

## ⚠️ Дисклеймер

Все расчёты носят **справочный характер** и не заменяют клиническое мышление. Клинические решения принимает лечащий врач на основании полного обследования пациента. Автор не несет ответственности за возможные последствия использования данных расчетов.
